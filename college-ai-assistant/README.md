# CampusAI: College AI Assistant (RAG + Memory + Source Grounding)

A fast local prototype for a Deep Learning project. It includes a chat UI, document upload, retrieval over PDFs/TXT/Markdown, source cards, simple persistent memory, conversation history, and optional local LLM generation through Ollama.

> **Important:** `documents/sample_college_handbook.txt` is synthetic demo content, not official college policy. Upload current documents that you are allowed to use. This prototype is not production-ready and has no authentication.

## Features
- RAG-style document pipeline: extraction → chunking → embeddings/TF-IDF retrieval → prompt context.
- Sentence Transformers embeddings when installed and the model can be downloaded; otherwise TF-IDF fallback.
- Source cards built from retrieved metadata, not generated by the LLM.
- Optional Ollama integration. If Ollama is unavailable, the app still demonstrates retrieval and returns relevant excerpts.
- Local JSON-backed conversation history and user-managed memories.
- Upload PDF, TXT, and Markdown files (12 MB maximum).

## Quick start (Windows PowerShell)
1. Install Python 3.11 (recommended) and, optionally, [Ollama](https://ollama.com/).
2. Open this folder in VS Code.
3. Create a virtual environment:
   ```powershell
   py -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```
4. Install dependencies:
   ```powershell
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   ```
   If `sentence-transformers` takes too long or fails, you can still run the app using TF-IDF fallback by installing the smaller set:
   ```powershell
   pip install fastapi "uvicorn[standard]" python-multipart pypdf requests scikit-learn
   ```
5. (Optional, for LLM answers) Install Ollama, then in a second terminal run:
   ```powershell
   ollama pull qwen2.5:3b
   ollama serve
   ```
   If Ollama isn't installed/running, retrieval-only mode still works.
6. Start the app from the project root:
   ```powershell
   uvicorn app.main:app --reload
   ```
7. Open http://127.0.0.1:8000

## Configuration
The defaults use `http://localhost:11434/api/generate` and model `qwen2.5:3b`. You can set environment variables before running:
```powershell
$env:OLLAMA_URL="http://localhost:11434/api/generate"
$env:OLLAMA_MODEL="qwen2.5:3b"
uvicorn app.main:app --reload
```

## Demo flow
1. Open the app and ask: "What does the sample handbook say about attendance?"
2. Check the source card returned below the answer.
3. Open **Knowledge base**, upload an official PDF/TXT/MD file you are allowed to use.
4. Ask a question answerable from that file.
5. Open **Saved memory** and add a harmless preference, e.g. "I prefer step-by-step explanations".
6. Ask a related question and demonstrate that relevant saved memory can be used.
7. Stop Ollama or leave it unavailable to demonstrate retrieval-only fallback.

## API endpoints
- `GET /api/health`
- `GET /api/documents`
- `POST /api/upload` (multipart form field `file`)
- `POST /api/chat` JSON: `{ "message": "...", "conversation_id": "default" }`
- `GET /api/history?conversation_id=default`
- `DELETE /api/history?conversation_id=default`
- `GET /api/memory`
- `POST /api/memory` JSON: `{ "memory": "..." }`
- `DELETE /api/memory/{memory_id}`

## Limitations to mention in the report
- No login/authentication or multi-user isolation.
- Local JSON persistence is intended for a demo, not concurrent production use.
- Embedding model downloads may require internet on first run.
- OCR for scanned PDFs is not implemented.
- Source citations point to retrieved document/chunk, not a guaranteed exact claim-level citation.
- LLM output and retrieval quality need evaluation on a labelled question set.
- TF-IDF fallback is information retrieval, not a neural embedding model; use the sentence-transformers path for the embedding experiment.

## Suggested Deep Learning evaluation
Create 30–50 questions with expected documents. Compare retrieval Recall@3 with sentence embeddings versus TF-IDF, then record answer correctness, citation support, abstention behavior, and latency. Do not report results until measured.
